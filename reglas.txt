```
https://gangasofertas.com/chollos-de-amazon.html https://gangasofertas.com/general.html 301
https://gangasofertas.com/articulos-rebajados-amazon.html https://gangasofertas.com/general.html 301

```

## Comprobacion tras crearlas

```bash
curl -sI https://gangasofertas.com/chollos-de-amazon.html | Select-String -Pattern 'HTTP|location'
```

Debe devolver `HTTP/2 301` y `location: https://gangasofertas.com/general.html`.
Cloudflare tarda unos minutos en propagar la regla.

## PrimeDays: decidir antes de redirigir

Las ocho URLs de la seccion PrimeDays tambien se retiraron ese dia.
A diferencia de estas cuatro, aqui el 301 depende de Search Console:

- **Con impresiones** → aplica 301 hacia su equivalente en `/BlackFriday/`:

  - `https://gangasofertas.com/PrimeDays/index.html` → `https://gangasofertas.com/BlackFriday/index.html`
  - `https://gangasofertas.com/PrimeDays/que-es-amazon-prime-days.html` → `https://gangasofertas.com/BlackFriday/que-es-el-black-friday.html`
  - `https://gangasofertas.com/PrimeDays/fechas-amazon-prime-days.html` → `https://gangasofertas.com/BlackFriday/fecha-black-friday-2026.html`
  - `https://gangasofertas.com/PrimeDays/ofertas-prime-days-2026.html` → `https://gangasofertas.com/BlackFriday/ofertas-black-friday-2026.html`
  - `https://gangasofertas.com/PrimeDays/descuentos-reales-o-falsos.html` → `https://gangasofertas.com/BlackFriday/gangas-black-friday.html`
  - `https://gangasofertas.com/PrimeDays/como-aprovechar-prime-days.html` → `https://gangasofertas.com/BlackFriday/como-aprovechar-black-friday.html`
  - `https://gangasofertas.com/PrimeDays/canal-telegram-ofertas.html` → `https://gangasofertas.com/BlackFriday/canal-telegram-ofertas.html`
  - `https://gangasofertas.com/PrimeDays/faq.html` → `https://gangasofertas.com/BlackFriday/faq.html`

- **Sin impresiones** → no hace falta redirigir. Una URL que nunca se
  posicionó no tiene peso que traspasar y un 404 no penaliza. Ahorra
  ocho reglas que no hacen falta.
